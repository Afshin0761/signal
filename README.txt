# Faran Trading Intelligence 1.2 — Signal Bot (بله)

## قابلیت‌های این نسخه
- موتور سیگنال: خرید قوی / خرید / خنثی / فروش / فروش قوی
- امتیاز ۰ تا ۱۰۰ با دلایل شفاف
- ارسال خودکار سیگنال‌های قوی به پیام‌رسان بله
- داشبورد زنده با فیلتر سیگنال
- تازه‌سازی هر ۳۰ ثانیه

## اجرا در ویندوز
1. Python 3.10 یا جدیدتر را نصب کنید (Add to PATH فعال باشد).
2. فایل‌ها را Extract کنید.
3. روی `run.bat` دوبار کلیک کنید.
4. آدرس `http://127.0.0.1:8000` را در مرورگر باز کنید.

## تنظیم بله (Bale)

### مرحله ۱: ساخت بازو (ربات)
1. در پیام‌رسان بله، به @BotFather پیام دهید.
2. دستور `/newbot` را بزنید و نام بازو را انتخاب کنید.
3. توکن را کپی کنید.

### مرحله ۲: گرفتن Chat ID
1. بازوی خودتان را Start کنید و یک پیام بفرستید.
2. این آدرس را در مرورگر باز کنید (توکن را جایگزین کنید):
   `https://tapi.bale.ai/bot<TOKEN>/getUpdates`
3. مقدار `chat.id` (یا `from.id`) را کپی کنید.

### مرحله ۳: تنظیم config.json
فایل `config.json` را باز کنید:

```json
{
  "bale_bot_token": "توکن_بازو_شما",
  "bale_chat_id": "چت_آیدی_شما",
  "bale_enabled": true,
  "min_score_to_notify": 45,
  "notify_signals": ["خرید قوی", "فروش قوی"],
  "poll_interval_seconds": 30
}
```

سپس سرور را Restart کنید و از دکمه «تست بله» در داشبورد اتصال را بررسی کنید.

## API
- `GET /api/health`
- `GET /api/market`
- `GET /api/signals?signal=خرید قوی&min_score=50`
- `GET /api/symbol/{ins_code}`
- `POST /api/refresh`
- `GET/POST /api/config`
- `POST /api/bale/test`

## نکات مهم
- این پروژه سفارش معاملاتی ارسال نمی‌کند؛ فقط سیگنال تحلیلی است.
- داده از endpoint عمومی TSETMC می‌آید.
- سیگنال‌ها بر اساس snapshot لحظه‌ای هستند.
- هیچ تضمینی برای سودآوری وجود ندارد.
